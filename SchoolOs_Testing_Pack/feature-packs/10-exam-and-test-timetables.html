Exam and test timetables

Follow only the cases assigned to you. Record what actually happens, even if the page is confusing or something goes wrong.

Who tests this: Exam officer; principal; owner; assigned teacher; parent

Before starting: A clean term, three prepared classes with subjects, plus a separate class with 13 subjects. Use only test exam dates.

Your test details

The web address is from the earlier staging setup. Your coordinator must confirm it. Enter only the app home address, never an invitation/reset link.

How to record each test

Passed: what should happen actually happened. Failed: it did not. Cannot test: you lack the account, data, connection or setup. Not tested: you have not tried it.

After a save, reload the app page to check it stayed saved. Test with invented records only. Never put passwords, activation codes, bank codes, card details or private links in this document.

Try without help first. If you need help, say so: that is useful feedback, even when the feature works.

Continue from a saved backup

For another tester or role, download the current report and backup first.

Answers stay in this browser when saving is available. The original checklist file does not contain your answers.
