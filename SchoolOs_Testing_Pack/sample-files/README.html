Sample files for SchoolOs testing

These files contain invented people. Use them only in the coordinator's disposable test school.

Do not upload every file into the shared fee baseline. The 30-student list and other upload experiments belong in a separate disposable class or school.

Student files

  • students-baseline-six.csv sets up the six shared students after the three exact classes exist.
  • students-names-only.csv tests first/last names only, with or without a selected class.
  • students-with-classes.csv tests different classes in one file and a blank class. Match the class names/arms to your test school.
  • students-invalid.csv deliberately contains missing names, duplicate admission numbers and an unknown class. It should fail validation.
  • students-leading-zeros.csv tests admission number 000123. If editing in Excel, format that column as Text before saving so Excel does not remove the zeros.
  • students-pagination-30.csv tests a default page of 25 students and the remaining five. Select a separate disposable class before uploading.

Staff invitations

staff-valid-template.csv needs real controlled test inboxes replacing the example.test addresses before upload. It contains only an email column. Do not send invitations to invented addresses or strangers.

staff-invalid.csv is deliberately invalid and should not send invitations.

Pictures

sample-school-logo.png is a small valid PNG for logo/profile-picture checks. invalid-picture.txt should be rejected as a picture.

Helpful reminders

  • Download the selected file, then choose it in the app's upload control. A CSV is an Excel-compatible text spreadsheet.
  • Use a simple header row and one person per row. Do not use formulas in the upload file.
  • If you prefer Excel, open a CSV, keep the column names, and save a copy as Excel Workbook with the xlsx extension. The app accepts xlsx and CSV.
  • Names-only files cannot identify the same person reliably across a completely new upload. Include admission numbers when checking for existing records. A saved retry is different: it should not duplicate its original upload.
  • Never put passwords or activation codes in the spreadsheet or returned report.
